## Context

The current setup for Event Bus makes on-call debugging slow and manual.

Event Bus needs predictable latency as traffic grows through the year.

## Decision

We will use Terraform for Event Bus.

## Consequences

The owning team updates the Event Bus runbook and the on-call notes.
