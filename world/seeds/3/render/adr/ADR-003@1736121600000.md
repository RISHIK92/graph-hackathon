## Context

Postgres Main is the shared relational store that Infra already operates with tested backups.

Ledger needs strict transactional guarantees for every double-entry posting.

## Decision

Ledger keeps postings and balances in one dedicated schema with strict transactional guarantees.

## Consequences

Infra runs backups and failover drills for the Ledger schema.
