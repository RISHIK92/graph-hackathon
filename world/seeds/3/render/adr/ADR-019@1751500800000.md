## Context

Kubernetes is already operated by other teams, so support costs stay low.

The current setup for Partner API makes on-call debugging slow and manual.

## Decision

We will use Kubernetes for Partner API.

## Consequences

The owning team updates the Partner API runbook and the on-call notes.
