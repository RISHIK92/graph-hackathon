## Context

Incidents on Session Store last quarter traced back to the existing approach.

The current setup for Session Store makes on-call debugging slow and manual.

## Decision

We will use ClickHouse for Session Store.

## Consequences

The owning team updates the Session Store runbook and the on-call notes.
