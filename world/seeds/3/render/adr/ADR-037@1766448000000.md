## Context

Moving to Temporal lets Event Bus scale without hand-tuned capacity.

Incidents on Event Bus last quarter traced back to the existing approach.

## Decision

We will use Temporal for Event Bus.

## Consequences

The owning team updates the Event Bus runbook and the on-call notes.
